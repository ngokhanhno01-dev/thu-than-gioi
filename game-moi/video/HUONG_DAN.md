# Video giới thiệu (phát cho người chơi lần đầu vào game)

Đặt file video vào đúng thư mục này, đặt ĐÚNG TÊN:

    gioi-thieu.mp4

(đường dẫn đầy đủ trong repo: game-moi/video/gioi-thieu.mp4)

- Định dạng: MP4 (H.264 + AAC) để máy nào cũng phát được.
- Dung lượng: tải lên GitHub bằng trình duyệt tối đa 25 MB mỗi file. Video khoảng 1p13s nén 720p, ~2 Mbps thì chừng 18 MB.
- Chưa có file này thì game tự bỏ qua, vào màn chờ như bình thường.
- Muốn thay video mới và cho người đã xem xem lại: đổi `key` ở đầu file game-moi/85-video-gioi-thieu.js (ttg_moi_intro_v1 -> ttg_moi_intro_v2).
- Muốn thử lại trên máy mình: thêm ?intro=1 vào link, hoặc đặt luonPhat: true trong file trên.
