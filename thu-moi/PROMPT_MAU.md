# Prompt mẫu tạo ảnh thú (đã chuyển chỗ)

**Khung prompt hiện hành (v2) nằm trong `thu-moi/PROMPT_LAM_VUNG_MOI.md`, mục "KHUNG PROMPT TẠO ẢNH".** Đó là nguồn duy nhất; KHÔNG chép khung sang file khác để tránh hai mẫu mâu thuẫn.

Bản v1 cũ (chi tiết ít, cấm tím / hồng, nền magenta cố định, "NO glow") đã bỏ khỏi file này vì ngược với quy tắc mới (thần thú nhiều chi tiết, màu và hiệu ứng theo vùng, nền ngược tông). Muốn xem lại thì dùng lịch sử git.

Bảng màu đã dùng:
- Tuyết Nguyên = deep navy, royal blue, sky blue, cyan, ice white.
- Sương Cốc = deep navy, deep teal, jade green, moss green, mist white.
- Vân Đảo = thân kem / trắng ngà, lavender / tím hồng ở mây và phù văn, tinh thể hồng tím, vàng nhạt, viền navy; nền tạo ảnh tím xanh đậm.

## Bài học còn hiệu lực
Viền lệch giữa các bậc, thân quá tối, mắt mất ở Bậc 2-3, hiệu ứng mờ trong suốt và pixel tím lẻ ngoài bảng màu. Dáng 4 chân hay ra giống nai / ngựa: thêm "NOT a deer, NOT a horse". Cần màu ngoài palette thì ghi rõ tên màu và chỗ dùng (Canva hay bỏ qua màu lục). Họa tiết cánh / thân không dùng đốm mắt giả (lẫn với mắt thật).
